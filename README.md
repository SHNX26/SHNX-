# SHNX

موقع مشاهدة مسلسلات بتصميم شبيه بنتفلكس. يسحب المحتوى من Google Sheets، والمحتوى ينضاف للشيت من بوت تيليجرام (Apps Script).

الرابط: https://shnx26.github.io/SHNX-/

## هيكل المشروع

| الملف | الوظيفة |
|---|---|
| `index.html` | هيكل الصفحة |
| `css/style.css` | التصميم |
| `js/config.js` | الإعدادات (رقم الشيت، أسماء الأوراق، رابط القناة) + بيانات احتياطية |
| `js/app.js` | منطق الموقع |
| `manifest.webmanifest`، `sw.js`، `icons/` | تثبيت الموقع كتطبيق على الجوال (PWA) |
| `apps-script/SHNX_Helpers.gs` | دوال جاهزة للبوت (إضافة حلقة، نشر تلقائي في القناة، حماية البوت) |

## أعمدة الشيت

أسماء الأعمدة ما تفرق فيها الحروف الكبيرة/الصغيرة، وترتيبها ما يهم.

### ورقة `Series` (المسلسلات)

| العمود | مطلوب؟ | الوصف |
|---|---|---|
| `name` | ✅ | اسم المسلسل (لازم يطابق الاسم في ورقة الحلقات حرف بحرف) |
| `cat` | | التصنيف: `trending` / `comedy` / `drama` / `horror` / `action` / `kids` / `shows` أو أي اسم عربي |
| `year` | | السنة |
| `genre` | | النوع (يظهر كوسم) |
| `img` | | رابط البوستر (طولي) |
| `desc` | | الوصف |
| `cover` | اختياري | صورة عرضية للبانر وصفحة المسلسل (لو فاضي يستخدم `img`) |
| `badge` | اختياري | وسم ذهبي مثل `🇸🇦 إنتاج محلي` |
| `quality` | اختياري | الجودة (الافتراضي `1080p HD`) |
| `total_eps` | اختياري | عدد الحلقات الكلي، والحلقات اللي ما نزلت تطلع "قريباً" |
| `top` | اختياري | ترتيبه في صف "الأكثر مشاهدة" (1 إلى 10) |
| `featured` | اختياري | اكتب `نعم` عشان يظهر في البانر المتحرك فوق |

> آخر صف في الورقة = الأحدث، ويظهر أول شي.

### ورقة `Sheet1` (الحلقات)

| العمود | مطلوب؟ | الوصف |
|---|---|---|
| `series` | ✅ | اسم المسلسل |
| `episode` | ✅ | رقم الحلقة |
| `link` | ✅ | رابط الـ embed |
| `season` | اختياري | رقم الموسم (الافتراضي 1). لو فيه أكثر من موسم تطلع أزرار المواسم تلقائياً |
| `title` | اختياري | عنوان الحلقة |
| `added_at` | اختياري | تاريخ الإضافة `yyyy-MM-dd HH:mm`، ويطلّع شارة "حلقة جديدة" أول 3 أيام |

> لو أضفت نفس الحلقة مرتين (تصحيح رابط مثلاً) الموقع يعتمد آخر صف.
> صف "أحدث الحلقات" في الرئيسية مبني على آخر الصفوف في هذي الورقة.

## المزايا

- بانر متحرك (سحب يمين/يسار) + صفوف: أكمل المشاهدة، أحدث الحلقات، الأكثر مشاهدة، قائمتي، والتصنيفات
- صفحة تصفّح فيها أزرار تصنيفات وبحث ذكي يتجاهل الفروق مثل ة/ه و أ/ا و ڤ/ف
- أكمل المشاهدة لأكثر من مسلسل، وعلامة ✓ على الحلقات اللي شفتها
- المواسم، والحلقة السابقة/التالية (تنتقل للموسم اللي بعده تلقائياً)
- روابط مباشرة لكل مسلسل وحلقة: `?s=كحيلان&e=5` (و`&ss=2` للموسم الثاني)، مع زر مشاركة
- زر الرجوع في الجوال يشتغل صح
- يفتح فوراً من آخر نسخة محفوظة ويحدّث من الشيت في الخلفية، ولو الشيت ما رد خلال 10 ثواني يكمل بالمحفوظ
- يتثبت كتطبيق على الجوال (من المتصفح: "إضافة إلى الشاشة الرئيسية")

### الحركة والانتقالات
- شعار متحرك عند الدخول (مرة وحدة في كل زيارة)
- البانر: النص يطلع كلمة كلمة، وشريط تقدم داخل النقطة يوضح متى ينتقل
- الصفوف والكروت تدخل بالتتابع، والصور تطلع من الضبابية
- البوستر يكبر ويتحول لغلاف صفحة المسلسل، ويرجع لمكانه عند الرجوع
- صفحة المسلسل: إضاءة خلفية من لون البوستر، والغلاف يتحرك مع النزول، والمحتوى يدخل بالتتابع
- أرقام الحلقات بمربعات زجاجية لامعة، والحلقة الشغالة تتوهج بالأحمر
- شريط قفز سريع (1–10، 11–20 ...) يثبت فوق، وزر لعرض الحلقات كمربعات
- نزول ناعم لآخر حلقة شفتها مع نبضة عليها
- اهتزاز خفيف عند الضغط (أندرويد)، وكل الحركات تتوقف لو الجوال مفعّل "تقليل الحركة"

## البوت (Apps Script)

شوف التعليمات في أول ملف [`apps-script/SHNX_Helpers.gs`](apps-script/SHNX_Helpers.gs). باختصار:

1. الصق الملف كملف جديد في مشروع Apps Script حق الشيت.
2. حط `BOT_TOKEN` و `ADMIN_IDS` و `CHANNEL_ID` و `SITE_URL` في Script Properties.
3. من كود البوت استخدم `shnxIsAdmin(chatId)` للحماية، و `shnxAddEpisode(...)` للإضافة. الدالة تضيف التاريخ تلقائياً وتنشر في القناة بوستر وزر يفتح الحلقة مباشرة.

## ملاحظات

- لو غيّرت ملفات الموقع وما ظهر التحديث عند الناس، غيّر رقم `CACHE` في `sw.js` (مثلاً `shnx-v3`).
- خلي الشيت مشارك "عارض" (Viewer) بس، لأن رقمه ظاهر في الكود.
